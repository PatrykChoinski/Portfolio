# Portfolio

- Pracuj lokalnie. Każdą zakończoną zmianę zapisuj w lokalnym commicie. Push tylko na bezpośrednie polecenie użytkownika.
- Nie publikuj nazw klientów, danych dostępowych ani surowych plików przemysłowych. Stosuj „Firma z branży …”.
- Opisy kompetencji muszą mieć podstawę w projektach lub CV. Nie wymyślaj referencji, wyników liczbowych ani autorstwa.
- Treści publiczne: src/data.mjs. Prywatne materiały źródłowe trzymaj poza śledzonym repo.
- Przed zakończeniem: npm test, npm run cv, npm run build, npm run test:e2e.
